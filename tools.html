Safe tools,
verified yourself.

An SS tool runs during a live investigation — often on a player's machine, always in front of a recording. A wrong download here means malware in your staff team or your players. Use the rubric below on any tool someone hands you, ours included.

The 7-point safety rubric

Score a tool before it ever touches a case. Three misses and it doesn't ship to your staff.

  1. Official source onlyDownload from the project's own domain over HTTPS — never a Discord DM, a shortened link, or a "mirror" from a video description. Fake download sites for popular tools are an industry of their own.
  2. Verifiable publisherSigned binaries (Authenticode / osascript), a public repo, or a code audit. Open-source core is best; closed tools need strong public provenance instead.
  3. No security disablingLegitimate scanners never ask you to turn off antivirus, add exclusion folders, or load unsigned kernel drivers. That request is the whole scam.
  4. Transparent data behaviorKnow what leaves the machine: hashes? screenshots? process lists? Cloud upload may be fine for a scan session — surprise telemetry is not.
  5. Honest pricingFree or plainly priced. "Discounted pins" from resellers, cracked builds, and lifetime keys sold in chat are fraud vectors, not deals.
  6. Community provenanceUsed by networks whose public SS policies you can actually read. Reputation among staff teams is the closest thing this ecosystem has to certification.
  7. Stays in its laneTools detect; humans decide. Marketing that promises "instant bans" or undetectability is selling you someone else's bypass — walk away.

The directory

What's actually out there for Minecraft SS work. No downloads are hosted here — check every link yourself.

Ocean SS Tool

Widely deployed

anticheat.ac · github.com/Ocean-SS-Tool

  • Free automated screenshare tool used across Minecraft and other games; scans run via session "pins".
  • Published detection logs and docs — you can see what it claims to find and why.
  • Companion Spigot plugin Ocean-Freeze is open source on GitHub, and the org publishes its other code publicly.
  • Core client is closed — trust rests on its public docs and widespread staff adoption, not a source audit.
  • Download only from anticheat.ac. Lookalike sites and "free pin" offers are the common scam.

FreeEcho

Established — verify source

freeecho.net

  • Long-running detection platform named alongside Ocean in major networks' public SS policies (e.g. PikaNetwork's).
  • Flexible enough that servers build their own scan flows on top of it.
  • Older ecosystem with scattered tutorials — confirm the current official domain through your server's staff chain before installing anything.
  • Remember the rule it lives under: scan results still get double-checked manually.

Meow Client Fucker

Community scan tool · verify source

meowclientfucker.dev · github.com/meowcf

  • Open-party launcher/scan helper that lists the mods and overclocks a match against the server's allow list.
  • Free, open core on GitHub — the rubric's 'verifiable publisher' line is easiest to satisfy here.
  • Works as a companion to a proper scanner: it produces a list, not a verdict, and it can be pointed at any .minecraft path.
  • Confirm the official domain through your server's staff chain — lookalike clones of the name are the most common distribution trap.

JavaTweak Client Suite

Community scan tool · verify source

javatweak.org · github.com/javatweak

  • Profiles the running JVM: which jars are loaded, start-time args, and the tweaker class on the command line.
  • Pure client-side analysis — no kernel drivers, no AV exclusion requests, no cloud upload.
  • Useful for the 'modules: N · injected: M' line you have to read yourself before citing it.
  • Open core on GitHub; check the repo's README and release signing before first use.

Microsoft Sysinternals

Gold standard · no-tools core

learn.microsoft.com/sysinternals

  • Process Explorer — Task Manager that actually shows command lines and what's injected into javaw.exe.
  • Autoruns — every startup, Run key, scheduled task and shell extension on the box, in one list.
  • Signed by Microsoft, free, decades of trust. If you learn exactly two tools, learn these.
  • Perfect backup when a server's scanner is down — the manual walk doesn't need one.

Remote access (AnyDesk / TeamViewer)

Official builds only

anydesk.com · teamviewer.com

  • The standard connection layer: players install from the official site and give you their ID.
  • Identity cuts both ways — the player may verify you before sharing control. That's procedure, not suspicion.
  • Never let anyone install a remote tool from a link you were DM'd. Ever.
  • Record from first contact; the connection ID belongs in the report.

Also out there: community guides (Red Lotus, screenshare.wiki) — teaching material, not tools. Their most quoted rule is the one this site drills: every tool's detection gets double-checked by hand before it becomes a ban.

Red flags — close the tab

Patterns that show up in fake and malware-laced "SS tools".

Scam pattern

Crossed-out prices on "pins"

Resellers, cracked builds, and lifetime keys sold in DMs. Legit tools don't distribute through resellers.

Scam pattern

"Disable your antivirus first"

Real scanners don't need exclusions. An AV warning on a fresh download is the tool telling you the truth.

Scam pattern

Lookalike domains & short links

Hyphens, extra words, bit.ly-style redirects from a YouTube description. Typo-squats on popular tool names are deliberate.

Scam pattern

"Undetectable / bypass included"

That's the cheat market wearing a moderator costume. Staff tools detect; they don't sell invisibility.

Scam pattern

No documentable source

Nowhere to read what it does, who makes it, or what it uploads — just a download button and a Discord invite.

Scam pattern

Asks for credentials or tokens

No scan needs a password, a session cookie, or a screenshot of a login. Refusing is a player right; asking is a fireable move.

House rule

This site hosts no binaries and takes no downloads from anyone. Read the rubric, check the source, keep the recording — and follow your server's written SS policy over anything here when they differ.

Tool questions, answered

The five questions staff ask before they let anything touch a player's machine.

Is the Ocean SS Tool safe to use on my Minecraft server?

Ocean is the most widely deployed free automated Minecraft screenshare scanner, and it publishes its detection logs and documentation — you can see what it claims to find and why. Its companion freeze plugin is open source on GitHub. The core client is closed source, so trust rests on its public docs and staff adoption rather than a source audit. Download only from anticheat.ac: lookalike domains and “free pin” offers are the standard way this one gets impersonated, and no legitimate scanner ever asks you to disable your antivirus.

What is FreeEcho and how does it compare to Ocean?

FreeEcho is one of the two long-running detection platforms named alongside Ocean in major networks’ public screenshare policies, and networks build custom scan flows on top of it. It is free, but its ecosystem has scattered tutorials — confirm the current official domain through your server’s staff chain before installing it on any staff machine. Same rule as Ocean: it produces leads, and you still open every hit by hand.

What is the safest screenshare tool for Minecraft staff?

Microsoft Sysinternals. Process Explorer is a Task Manager that actually shows command lines and what is injected into javaw.exe; Autoruns lists every startup entry, Run key, scheduled task and shell extension in one view. Both are signed by Microsoft, free, and decades trusted — and they need no third party at all, which also makes them the right fallback when a server’s scanner is down or you do not trust it.

How do I know if a Minecraft SS tool is a scam?

Run the 7-point rubric above and walk away at three misses. In practice the pattern is always the same: it comes from a DM or a short link rather than a domain, it wants antivirus disabled or an exclusion folder added, it sells “pins” at a discount or offers a cracked build, it promises instant bans or undetectability, or it asks for your password, a token or a screenshot of a login. Any one of those ends the evaluation there.

Do I need an SS tool at all, or can I screenshare manually?

No tool is required — the manual walk covers most of what scanners find: processes and command lines, the .minecraft instance, installed programs and dates, startup and Run keys, Prefetch execution history, and Windows services. Tools only speed up triage. Every detection still has to be opened and verified by hand before it can go in a report, because an unverified detection is worth nothing at appeal.
